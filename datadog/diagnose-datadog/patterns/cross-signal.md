# Cross-signal correlation

Anchor the investigation to a service, environment, version/deployment, and UTC window. Establish impact from SLO/RUM/synthetic/incident data, change point from deployments/events, failure path from traces, explanation from bounded logs, and saturation from metrics. Normalize universal service tags before joining. Missing correlation is a telemetry-quality finding; do not invent linkage from similar timestamps alone.

For cross-platform work, return identifiers and evidence links suitable for the Spring Boot, Azure, Kubernetes, database, CI, or data-platform router. Do not widen those scopes implicitly.
