# Incidents

1. Build a UTC timeline from alerts, deploys, events, ownership changes, and confirmed actions; preserve source links.
2. Separate observations, hypotheses, decisions, and remediation outcomes.
3. Map affected services through the Software Catalog and dependency evidence, then quantify user impact with bounded telemetry.
4. Record evidence gaps and contradictory signals; do not let incident summaries turn inference into fact.
5. Draft updates or postmortems only. Declaring, updating, paging, or closing incidents requires authorization.

Use `knowledge/evidence.jsonl` with `area=incidents`.
