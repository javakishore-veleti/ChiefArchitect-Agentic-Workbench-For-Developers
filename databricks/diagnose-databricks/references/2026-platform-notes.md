# Data + AI Summit 2026 notes

The summit ran June 15–18, 2026. The Lakeflow announcement was published June 16 and updated July 1. As announced: Lakeflow Designer was GA; Real-Time Mode for Spark Declarative Pipelines was Public Preview; Community Connectors and several managed connectors were Beta; Kafka-compatible Zerobus APIs were described as Beta/coming soon; REST, gRPC, and listed SDKs were GA. Lakeflow Jobs announced external orchestration and 50+ integrations, with managed integrations still being added.

The June 17 AI announcement described AI Runtime as Public Preview, with multinode training support; Genie Code for ML and enhanced real-time Feature Store/Model Serving capabilities were announced. These notes are historical claims, not present-tense entitlement. Before use, verify current documentation, cloud, region, edition, account flags, and release notes.
