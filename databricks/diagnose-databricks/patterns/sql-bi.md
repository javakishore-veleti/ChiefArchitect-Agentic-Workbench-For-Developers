# SQL, BI, and semantic access

Capture statement/query ID, warehouse, user, client, dashboard, time window, parameters, and expected freshness. Inspect query profile, scan/pruning, spill, shuffle, cache, queue, concurrency, materialized-view refresh, permissions, and upstream freshness. For BI tools, isolate connector/authentication from SQL execution. Verify AI/BI Genie space instructions and trusted assets before accepting generated analysis. Never expose row-level data or query text containing secrets in summaries.
