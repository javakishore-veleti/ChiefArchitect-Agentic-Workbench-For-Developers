# Sharing and interoperability

Resolve provider, recipient, share, object, profile/credential, table format, cloud, and client. Inspect grants, recipient activation, token or OIDC expiry, network policy, sharing audit events, table features, and protocol/client compatibility. For Iceberg/foreign catalogs/federation, distinguish metadata visibility from data-plane access and write support. Prefer open protocol evidence; never rotate recipients, credentials, or table formats without authorization and rollback.
