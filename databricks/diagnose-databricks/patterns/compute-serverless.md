# Compute and serverless

Classify interactive, jobs, pipeline, SQL warehouse, serving, or GPU compute. Inspect policy, access mode, runtime/channel, libraries, startup events, capacity, autoscaling, Photon, network reachability, and termination. For serverless, confirm cloud/region/workload support and required connectivity; it is not interchangeable with classic compute. Separate queue time, provisioning time, execution time, and downstream wait. Compare right-sized alternatives using measured utilization and workload SLOs, not cluster size alone.
