# Workspace, identity, and networking

Resolve account, workspace, cloud, region, deployment model, identity, authentication method, network boundary, private endpoints, DNS, firewall, storage, and KMS. Test control-plane authentication separately from data-plane reachability. Check OAuth/service-principal scope, federation, storage credentials, external locations, routes, and name resolution without revealing tokens. Never weaken public access, firewall, private-link, or encryption controls to prove a hypothesis.
