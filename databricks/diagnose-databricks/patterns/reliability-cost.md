# Reliability and cost

Build a timeline across system tables, jobs/pipelines, SQL, serving, audit, and cloud dependencies. Separate platform outage, quota/capacity, configuration drift, code/data defect, dependency failure, and workload saturation. For cost, allocate by account/workspace/tag/SKU/workload and correlate usage with useful work, failures, retries, idle periods, and SLOs. Avoid estimates from list price alone. Any cancellation, repair, rerun, optimization, retention, or capacity change requires impact assessment and explicit authorization.
