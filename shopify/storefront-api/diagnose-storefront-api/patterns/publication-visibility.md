# Publication and visibility

First determine whether the resource is active, published to the token's sales channel, available in the requested market, and within publication dates. Compare Admin visibility with Storefront visibility only after identifying the publication associated with the token.

A resource visible in Admin, another storefront, preview, or a different market does not prove Storefront API visibility. Do not republish or alter channel assignments during diagnosis. Route field-level product, collection, metafield, or metaobject behavior to the products skill after this gate.

Official reference: https://shopify.dev/docs/apps/build/purchase-options/product-availability
