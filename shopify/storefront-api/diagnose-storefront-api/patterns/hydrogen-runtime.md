# Hydrogen request behavior

Capture Hydrogen/Oxygen version, selected app, route, server-versus-browser execution, cache mode, session state, request headers, and whether hard refresh differs from client navigation. Verify that environment bindings resolve to the intended shop and token.

Separate Storefront API response correctness from loader, suspense/defer, hydration, metadata ordering, session, caching, and deployment failures. Reproduce the GraphQL request outside rendering; if it is correct, keep the investigation in Hydrogen rather than changing Shopify data.

Official references: https://shopify.dev/docs/storefronts/headless/hydrogen and https://shopify.dev/docs/storefronts/headless/hydrogen/caching
