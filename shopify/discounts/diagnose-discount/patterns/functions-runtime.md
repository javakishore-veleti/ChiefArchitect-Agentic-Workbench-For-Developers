# Discount Functions runtime

Verify the deployed extension, function ID/handle, API version, registered target, discount classes, and discount-node binding. Capture the exact Function input and output from a safe reproduction; distinguish “Function not invoked,” “invoked with unexpected input,” and “returned no valid operation.” Check configuration metafield namespace/key/type and input-variable binding. Functions have constrained runtime capabilities; do not assume arbitrary network access. Compare deployments by immutable artifact/version and configuration rather than environment names.

Official: https://shopify.dev/docs/api/functions/latest/discount
