# Shopify Admin API skills

One exposed router handles Admin GraphQL diagnosis without flooding the harness with issue-specific skills.

| Component | Count | Purpose |
|---|---:|---|
| Exposed skill | 1 | Classify and route natural-language Admin API problems |
| Diagnostic patterns | 10 | Load only the matched procedure |
| Community issue records | 29 | Real problem signals, paraphrased and non-authoritative |
| Deterministic scripts | 4 | Classify, execute, summarize and compare |
| GraphQL queries | 4 | Reusable minimal diagnostics and bulk-operation starter |
| Automated tests | 3 | Verify core routing behavior with synthetic inputs |

The skill discovers enterprise topology dynamically. It does not hardcode industries, storefronts, shops or environment names.
