# Observability and cost

Use run, attempt, workflow, job, step, repository, SHA, event, runner group, and deployment environment as correlation fields. Analyze queue versus execution time, reruns, cancellations, cache hit rate, artifact transfer/retention, matrix fan-out, runner utilization, and billable minutes. Emit step summaries and structured external telemetry without secrets.

Optimize only after measuring: cancel superseded work, reduce duplicate matrices, right-size runners, reuse verified artifacts, tune caches, bound retention, and separate flaky retries from legitimate reruns. Preserve required controls and test coverage.
